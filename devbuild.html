Install the Honestech test build

This is a test version of the iPhone app for trying Tap to Pay on iPhone. It only installs on iPhones that were registered for testing.

Install the test build
  1. Open this page in Safari on the registered iPhone and tap Install the test build, then Install.
  2. Go to the Home Screen and wait for the app to finish downloading. It replaces the App Store or TestFlight version; your jobs stay synced.
  3. The first time only: Settings → Privacy & Security → Developer Mode → on, then restart the iPhone and tap Turn On.
  4. Open the app. Go back to TestFlight or the App Store any time to switch back.

"Unable to install"? The iPhone isn't registered yet, or a newer test build is still being made. Push notifications don't arrive in test builds.
